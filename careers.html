Robotics Simulation & Control Engineer

View Full Job Description (PDF)

Robosloth Technologies is seeking a Control Engineer, You’ll work closely with our Robotics Testing Engineer to bring virtual models to life — validating algorithms, improving performance, and shaping real-world robot behaviour.

Responsibilities:

  • Run experiments to validate control and learning performance, using simulation-to-real (sim2real) strategies.
  • Develop and tune real-time control software for dynamic, adaptive behavior.
  • Collaborate closely with the Robotics Testing Engineer to align simulation with hardware constraints and sensor feedback.
  • Document and present findings in a structured, reproducible format.

Requirements:

  • Master’s degree in Robotics, Mechatronics, Control Engineering, Computer Science, or related field.
  • Solid programming experience in Python and C++ (preferred).
  • Familiarity with ROS/ROS2.
  • Strong problem-solving and prototyping mindset — able to find clever workarounds and move quickly.

Robotics Testing Engineer

View Full Job Description (PDF)

Robosloth Technologies is seeking a hands-on Robotics Testing Engineer to validate our crawling and climbing robot prototypes. You'll lead experimental testing, analyse real-world behaviour, and work closely with our Simulation & Control team to bridge virtual models with hardware reality.

Responsibilities:

  • Plan and run robot prototype tests — functional, control, and reliability.
  • Collaborate with simulation/control engineers on sim2real validation.
  • Design test rigs, setups, and data acquisition workflows.
  • Analyse motion and sensor data to diagnose issues and propose improvements.
  • Document tests with clear logs and reproducible reports.

Requirements:

  • Bachelor’s degree in Mechanical Engineering, Mechatronics, or Robotics.
  • Hands-on experience building and testing hardware.
  • Familiarity with ROS/ROS2, sensors, and data acquisition tools.
  • Strong analytical and troubleshooting skills.
